词汇表

课里第一次出现的术语先在这里落地。每条一两句，链到首次使用的课。按主题分组，组内按出场顺序。

工具与读码

bpy

Blender 的 Python API 模块。官方二进制内置 Python 解释器，控制台里 import bpy 后，场景里几乎所有数据都能摸到。本路径的实验都靠它，不用编译。

首次使用：0.1 工具就位

Python 控制台

Blender 里的交互式解释器（Scripting 工作区，或任意区域切成 Console）。Ctrl+Space 补全，dir() 列成员。输入一行立刻看到结果，是观察设计的最近距离。

首次使用：0.1 工具就位

源码树

本仓库 checkout 出来的 Blender 源码。读码时主要逛三个目录：source/（主体）、intern/（Cycles 等内部库）、scripts/（Python UI）。

首次使用：0.1 工具就位；分工详表见 overview.md

符号

函数名、结构体名、宏名的统称。读码的基本功是「给一个符号，能在源码树里 grep 到它的定义」。课里所有英文标识符都是真实符号，可以在树里搜到。

首次使用：0.1 工具就位

数据块与 ID

数据块（data-block）

Blender 里「一个东西」的统称：物体、网格、材质、场景、相机……每个数据块开头都是同一个 ID 头，所以它们共享名字、用户计数、存盘规则。

首次使用：1.1 一切都是数据块

ID

每个数据块开头的公共结构（DNA_ID.h 的 struct ID）。里面有名字（前两字节是类型码，网格是 ME）、用户计数 us、脏标记 recalc、自定义属性 properties。

首次使用：1.1 一切都是数据块

用户计数（users）

ID 头上的整数：这份数据被几个地方引用。两个物体共用一份网格，网格的 users 就是 2。减到 0 的数据块才可能被清掉。

首次使用：1.1 一切都是数据块

伪用户（fake user）

数据块上的一个开关（bpy 里 use_fake_user）。打开后即使没人引用也存盘保留，防止「删掉最后一个使用者，数据块跟着消失」。

首次使用：1.1 一切都是数据块

孤儿数据块（orphan）

用户计数为 0 且没有伪用户的数据块。存盘时默认不写进去；bpy 里可用 bpy.data.orphans_purge() 立即清理。

首次使用：1.1 一切都是数据块

DNA 与文件

DNA

写进 .blend 的 C 结构布局，定义在 source/blender/makesdna/DNA_*_types.h。它只回答「这块内存怎么排」，不实现任何算法。磁盘上的真相。

首次使用：1.2 DNA 是磁盘布局

SDNA

构建期由 makesdna 工具扫描 DNA 头文件编出的「结构说明书」表。它既是当前进程的布局描述，也原样写进每个 .blend 的 DNA1 块，供旧版本对齐字段。

首次使用：1.2 DNA 是磁盘布局

.blend / DNA1

Blender 的存盘文件。里面按 DNA 布局顺序存所有数据块，末尾带 DNA1 块（这份文件用的 SDNA 表）。打开文件 = 按 DNA1 重建内存结构。

首次使用：1.2 DNA 是磁盘布局

runtime（运行时字段）

结构上明确不存盘的指针，例如 Mesh.runtime（MeshRuntime）。编辑态 BMesh、求值缓存都挂在这里。保存前必须能从中重建出纯 DNA 数据。

首次使用：1.2 DNA 是磁盘布局

RNA 与 Main

RNA

属性反射层：给 DNA 字段和运行时函数起对外名字、绑偏移、挂 update 回调。面板、Python bpy、Operator 属性都只认 RNA，不直接扫 C 结构体。

首次使用：1.3 RNA 是对外门面

bl_rna

bpy 里每个类型 / 实例都带的 RNA 自省入口。bpy.types.Mesh.bl_rna.properties 能列出 Mesh 对外暴露的全部属性——这就是 RNA 层在 Python 里的样子。

首次使用：1.3 RNA 是对外门面

Main

进程里全部数据块的数据库（BKE_main.hh 的 struct Main），按类型串起来的 ID 集合。bpy 里的 bpy.data 就是它的 Python 视图。一个 Blender 进程一份 Main。

首次使用：1.4 Main 与 Scene

Scene

「一幕场景」数据块：帧范围、渲染设置、当前 View Layer 指针等。它只是 Main 里的一块；一个文件可以有多个 Scene，bpy.context.scene 是用户正在看的那个。

首次使用：1.4 Main 与 Scene

后面阶段预告

Operator

一次用户命令的封装：可撤销、可快捷键、可被 Python 点名（bpy.ops.*）。有 poll / invoke / exec 三个回调。阶段 2 的主角。

首次使用：阶段 2（未开）；参考 数据 · Operator / WM

depsgraph（求值图）

把「谁依赖谁」编成图：标脏一块几何，只重算相关节点。视口和 F12 各用一张图。阶段 4 的主角。

首次使用：阶段 4（未开）；参考 渲染 · Depsgraph
