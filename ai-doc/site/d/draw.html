draw / View3D

视口先假定图已经求过

view3d_main_region_draw → DRW_draw_view（draw/intern/draw_context.cc）。这里 CTX_data_expect_evaluated_depsgraph：WM 循环里该求的已经求完。

渲染入口 Depsgraph Draw / 视口 EEVEE / Workbench F12 / Cycles

它解决什么

视口每帧要把求值后的物体变成 GPU 批次，再叠选择轮廓和编辑线。Draw Manager 假定 depsgraph 已经求过：它调度引擎，不跑修改器栈。

一帧

view3d_main_region_draw          /* view3d_draw.cc */
  view3d_draw_view
    ED_view3d_draw_setup_view(..., CTX_data_expect_evaluated_depsgraph(C), ...)
    DRW_draw_view                /* draw_context.cc */
      ED_view3d_engine_type(scene, v3d->shading.type)
      /* Material + RE_USE_EEVEE_VIEWPORT → 改找 BLENDER_EEVEE */
      drw_draw_render_loop_3d

引擎接口 DrawEngine（DRW_render.hh）：init / begin_sync / object_sync / end_sync / draw。物体网格批：BKE_object_get_evaluated_mesh* + draw_cache_impl_mesh.cc。

谁上、谁叠

  • 线框 / Solid → Workbench
  • Material + 多数引擎 → EEVEE（Cycles 也设了 RE_USE_EEVEE_VIEWPORT）
  • Rendered + Cycles → draw::external::Engine 的 view_draw
  • 然后几乎总开 overlay：选择轮廓、编辑线、网格、gizmo

Overlay 不是 RenderEngineType，活在 DRWViewData。F12 用的 EEVEE/Workbench 类型在 DRW_engines_register 里 RE_engines_register。

和邻居的边界

层它写什么它不写什么
depsgraph求值副本、修改器结果GPU 批次、overlay
Draw Manager选引擎、sync、draw拓扑、F12 调度
overlay选择轮廓、编辑线、gizmo不能当 scene.r.engine

设计选择

着色模式只改 View3D 启用哪组引擎。DNA Mesh 不动。

常见误解

overlay 不是渲染引擎。关掉 Solid 仍可能要选中高亮。

源码符号

DRW_draw_view · ED_view3d_engine_type · Q163 · Q166
