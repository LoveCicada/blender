depsgraph

没有叫 DEG_evaluate 的入口

对外是 DEG_evaluate_on_refresh（数据变了）和 DEG_evaluate_on_framechange（换帧）。包装在 BKE_scene_graph_update_tagged / BKE_scene_graph_evaluated_ensure。

渲染入口 Depsgraph Draw / 视口 EEVEE / Workbench F12 / Cycles

图里有什么

ID 节点 → 组件（TRANSFORM / GEOMETRY / SHADING …）→ 操作节点，边是 Relation。构建：DepsgraphNodeBuilder + DepsgraphRelationBuilder。视口 DEG_graph_build_from_view_layer；F12 DEG_graph_build_for_render_pipeline。

Copy-on-eval

原始 Main 里的 Object/Mesh 尽量不动。求值写副本（deg_eval_copy_on_write.cc）。查询：DEG_get_evaluated / DEG_get_original_id。网格：BKE_object_get_evaluated_mesh（可经 geometry_set_eval，再 BKE_mesh_wrapper_ensure_subdivision）。

两种模式

DAG_EVAL_VIEWPORT：Realtime 修改器、hide-viewport。场景里那张图由 BKE_scene_ensure_depsgraph 保证。DAG_EVAL_RENDER：Render 修改器、hide-render；F12 在 render_init_depsgraph 另建。这就是修改器图里上下分叉的来源。

内部阶段：COPY_ON_EVAL → 可见性 → 并行跑 OperationNode::evaluate（deg_eval.cc）。
