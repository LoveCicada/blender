editors/object

Tab 做了一次格式转换

idname OBJECT_OT_editmode_toggle（editors/object/object_edit.cc）。进模式：数组 → 半边。出模式：半边 → 数组。中间的工具不写 DNA。

建模入口 Mesh / BMesh 进出编辑模式 挤出与 BMO 修改器

它解决什么

用户按 Tab 只觉得「能改点了」。源码必须做一次格式转换：数组变成半边，模式标志换成 OB_MODE_EDIT。中间的挤出、溶解只改 em->bm，不每步写回 DNA。

进入

editmode_toggle_exec
  editmode_enter_ex
    ob->mode = OB_MODE_EDIT
    EDBM_mesh_make(ob, selectmode, ...)     /* editmesh_utils.cc */
      BKE_mesh_to_bmesh / BM_mesh_bm_from_me
      mesh->runtime->edit_mesh = make_shared<BMEditMesh>()
      BKE_editmesh_looptris_and_normals_calc
    DEG_id_tag_update(&ob->id, ID_RECALC_GEOMETRY)
    WM_main_add_notifier(NC_SCENE | ND_MODE | NS_EDITMODE_MESH, nullptr)

源码先检查 BKE_object_is_in_editmode、数据是否可编辑、是否库数据。同一份 Mesh 不能同时被多个物体开编辑（见注释 #86767）。

离开

editmode_exit_ex -> editmode_load_free_ex
  EDBM_mesh_load_ex(bmain, obedit, free_data)
    BM_mesh_bm_to_me(bmain, bm, mesh, &params)
  EDBM_mesh_free_data / BKE_editmesh_free_data
  edit_mesh.reset()

求值过程中还有 BM_mesh_bm_to_me_for_eval，给修改器一条临时数组，不代表用户已退出编辑。

留在编辑模式

工具改 em->bm，然后 EDBM_update（更新已写）：标 ID_RECALC_GEOMETRY + 重算法线/looptris。needs_flush_to_id 表示 DNA 过期。

和邻居的边界

函数写谁不代表什么
BM_mesh_bm_from_me新建半边，挂 edit_mesh用户已经挤出过
BM_mesh_bm_to_me半边写回 DNA 数组修改器已经 Apply
BM_mesh_bm_to_me_for_eval给修改器一条临时数组用户已退出编辑

设计选择

转换函数在 editors，真正拷数据在 bmesh convert。模式标志在 Object.mode，不在 bmesh 库里。

常见误解

Tab「看起来没变」不等于没转换。屏幕仍是同一物体，存储格式已经换了。
