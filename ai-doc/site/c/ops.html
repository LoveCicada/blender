editors/mesh

WM Operator 下面还有一层 BMO

数据章的 MESH_OT_subdivide 直接调 BM_mesh_esubdivide。挤出、溶解走统一运算符表：字符串名 + 槽位 + exec。

建模入口 Mesh / BMesh 进出编辑模式 挤出与 BMO 修改器

它解决什么

WM Operator 是用户命令（可撤销、可快捷键）。拓扑原语需要另一张表：字符串名 + 槽位，Python 和其它编辑器也能调。editors/mesh 只负责 poll、填选择、收尾 EDBM_update。

表在哪

bmesh/intern/bmesh_opdefines.cc 的 bmo_opdefines[]。调度：BMO_op_init / BMO_op_exec（bmesh_operators.cc）。编辑器常用 EDBM_op_callf(em, op, "dissolve_verts verts=%hv ...", BM_ELEM_SELECT)，把当前选择填进槽。

挤出

MESH_OT_extrude_region          /* editmesh_extrude.cc */
  edbm_extrude_ex
    BMO_op_init(..., "extrude_face_region")
    BMO_op_exec
      bmo_extrude_face_region_exec  /* bmo_extrude.cc */
  EDBM_update

用户菜单里常见宏 MESH_OT_extrude_region_move（mesh_ops.cc 的 WM_operatortype_append_macro）：挤出再接变换（transform modal）。edbm_extrude_ex 本体：

BMO_op_init(bm, &extop, BMO_FLAG_DEFAULTS, "extrude_face_region");
BMO_slot_buffer_from_enabled_hflag(..., "geom", htype, hflag);
BMO_op_exec(bm, &extop);
BMO_ITER (ele, ..., "geom.out", ...)
  BM_elem_select_set(bm, ele, true);
BMO_op_finish(bm, &extop);

溶解

"dissolve_verts" → bmo_dissolve_verts_exec（bmo_dissolve.cc）→ MESH_OT_dissolve_verts（editmesh_tools.cc）。和细分一样：poll 仍是 ED_operator_editmesh。

和邻居的边界

层它写什么它不写什么
WM Operator快捷键、undo、bContext半边重连算法
BMO槽位里的选择 → 改 BMesh不听 keymap
EDBM_update标脏 + 重算法线/looptris不立刻写回 DNA

设计选择

BMO 表放在 bmesh，不放 editors/mesh。用户命令和拓扑原语可以分开复用。

常见误解

细分有时直接 BM_mesh_esubdivide，挤出走 BMO。两条都合法，不是混乱。
