投影 2

按职责分层

同一份目录，按「这一层保证什么」切开。上层可以调用下层，不要绕过命令层直接改绘制缓存。

数据布局

makesdna、blenloader。保证文件里有稳定结构，不管按钮长什么样。

属性反射

makesrna。保证 UI 和 Python 用同一套名字读写字段。

运行时对象

blenkernel、geometry。保证 ID 活着、Mesh 合法。

拓扑编辑

bmesh。保证编辑模式能高效改连接关系。

命令

windowmanager 与 editors/*。保证一次用户动作可执行、可撤销、可重复。

UI

bl_ui、space_view3d。保证人能看见属性和视口工具，不负责算光。

依赖求值

depsgraph、modifiers。保证绘制/渲染拿到「应用过修改器的世界」。

视口绘制

draw、gpu、EEVEE、Workbench。保证交互帧。

离线渲染

render、Cycles。保证 F12 出图。与视口共享求值，不共享 DrawManager。

着色节点同时服务视口与离线，见 nodes/shader。
