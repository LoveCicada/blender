RNA：给 DNA 起名

RNA 是反射层：StructRNA 是类型，PropertyRNA 是属性，PointerRNA 是「指向哪块 DNA、属于哪个 ID」。UI 和 bpy 只认这一套名字。

数据入口 DNA RNA Python UI Operator / WM 更新与撤销

它解决什么

UI 和 Python 不能扫 C 结构体。RNA 把「这个字段叫什么、类型是什么、写完谁更新」做成反射。DNA 继续管磁盘；RNA 管对外契约。

三个类型

  • PointerRNA（RNA_types.hh）：owner_id + type + data。
  • StructRNA：如 "Mesh"，继承 "ID"，挂一串属性。
  • PropertyRNA：标识符、类型、SDNA offset 或 get/set、update 函数、noteflag。

定义时绑到 DNA

makesrna/intern/rna_mesh.cc 的 RNA_def_mesh 由构建工具 makesrna.cc 的 PROCESS_ITEMS 跑一遍，生成访问代码。

srna = RNA_def_struct(brna, "Mesh", "ID");

prop = RNA_def_property(srna, "remesh_voxel_size", PROP_FLOAT, PROP_DISTANCE);
RNA_def_property_float_sdna(prop, nullptr, "remesh_voxel_size");
RNA_def_property_update(prop, 0, "rna_Mesh_update_draw");

prop = RNA_def_property(srna, "use_auto_texspace", PROP_BOOLEAN, PROP_NONE);
RNA_def_property_boolean_sdna(prop, nullptr, "texspace_flag", ME_TEXSPACE_FLAG_AUTO);
RNA_def_property_update(prop, 0, "rna_Mesh_update_geom_and_params");

定义阶段 RNA_def_property_update(..., "rna_Mesh_update_...") 先存字符串，生成后再补成函数指针。Object 的 data 用 pointer funcs，不是单纯 offset：rna_object.cc 里 rna_Object_data_get/set。

写完为什么要 update

运行时入口很薄：RNA_property_update(C, ptr, prop) 立刻转到 rna_property_update(C, CTX_data_main(C), CTX_data_scene(C), ptr, prop)（rna_access.cc）。内部调用 prop->update，默认再 DEG_id_tag_update（可用 PROP_NO_DEG_UPDATE 关掉），并 WM_msg_publish_rna 刷新绑定该属性的控件。

/* rna_mesh.cc */
rna_Mesh_update_geom_and_params(...) {
  DEG_id_tag_update(id, ID_RECALC_GEOMETRY | ID_RECALC_PARAMETERS);
  WM_main_add_notifier(NC_GEOM | ND_DATA, id);
}

rna_Mesh_update_draw(...) {
  WM_main_add_notifier(NC_GEOM | ND_DATA, id);
}

改纹理空间这类几何相关属性走前者；很多「只影响显示」的走 rna_Mesh_update_draw。体素尺寸等还可带 PROP_NO_DEG_UPDATE，等你按 Remesh 按钮再算。

Python 怎么碰到 RNA

source/blender/python/intern/bpy_rna.cc：bpy.types.Mesh 是 StructRNA 的 Python 包装。赋值走 RNA_property_*_set，成功后 pyrna_py_to_prop 调 RNA_property_update。bpy.ops.mesh.subdivide() 不走属性，走 bpy_operator_function.cc → WM_operator_call_py。
