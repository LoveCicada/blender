按用户功能

从「我在软件里做什么」反查目录，并补上函数栈。着色块表示这条功能会碰到该模块；空白表示通常不走。

目录 模块 职责 功能 UI–数据 渲染地图

物体模式

选择物体、变换物体、进出编辑模式。editors/object、transform 改 Object / BKE，经 depsgraph 更新 draw。不进 BMesh，除非进入编辑模式。

物体模式按 G：keymap 指向 transform modal，写回 Object 的位置/旋转/缩放，标 ID_RECALC_TRANSFORM。网格数组不动。

Tab 进出编辑

idname OBJECT_OT_editmode_toggle（editors/object/object_edit.cc）。进模式：

editmode_toggle_exec
  editmode_enter_ex
    ob->mode = OB_MODE_EDIT
    EDBM_mesh_make(ob, selectmode, ...)     /* editmesh_utils.cc */
      BKE_mesh_to_bmesh
      mesh->runtime->edit_mesh = make_shared<BMEditMesh>()
    BKE_editmesh_looptris_and_normals_calc
    DEG_id_tag_update(&ob->id, ID_RECALC_GEOMETRY)

离开走 EDBM_mesh_load_ex → BM_mesh_bm_to_me。深讲：进出编辑模式。

编辑模式改网格

挤出、切割、点边面选择。editors/mesh 操作 bmesh。菜单常见宏 MESH_OT_extrude_region_move（mesh_ops.cc 里 WM_operatortype_append_macro）：先挤出再接变换。

MESH_OT_extrude_region          /* editmesh_extrude.cc */
  edbm_extrude_ex
    BMO_op_init(..., "extrude_face_region")
    BMO_op_exec
  /* 然后 EDBM_update 标脏 */

修改器

点添加只往 Object.modifiers 塞 ModifierData。变形在下一轮 BKE_object_eval_uber_data → mesh_calc_modifiers。视口读 eModifierMode_Realtime，F12 读 Render。Apply 才是 OBJECT_OT_modifier_apply，编辑模式不能 Apply。

材质与着色

节点画在 nodes/shader。EEVEE：GPU_material_from_nodetree（SHD_OUTPUT_EEVEE）。Cycles：add_nodes（SHD_OUTPUT_CYCLES）。不是同一份机器码。

视口显示

view3d_main_region_draw → view3d_draw_view → DRW_draw_view。ED_view3d_engine_type(scene, v3d->shading.type)：Material 且引擎带 RE_USE_EEVEE_VIEWPORT 时改走 EEVEE。线框/Solid 走 Workbench。不经过 Cycles kernel。

F12 渲染

RENDER_OT_render（render_internal.cc）→ RE_RenderFrame → RE_engine_render → RE_engines_find(scene.r.engine)。默认学习路径按 Cycles 记：BlenderSync::sync_data 吃求值物体。视口像素管线到此停。

和邻居的边界

用户动作进 BMesh？出像素的路
物体模式 G否视口重画物体矩阵
编辑模式 E是标脏后视口吃求值网格
F12否（先求值）RE_engine_render

设计选择

同一套 G：物体模式写 Object，编辑模式写 BMesh 顶点。

常见误解

视口带着细分预览 ≠ 已经 Apply。基网格顶点数可以仍是旧的。
