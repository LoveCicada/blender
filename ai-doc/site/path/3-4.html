3.4 挤出与 BMO

Blender 有两张操作符表：2.1 的 WM 表管「用户命令」（上下文、撤销、界面），BMO 表管「几何算法」（输入一槽几何，输出一槽几何）。挤出把两张表串了起来。

路径索引 3.3 编辑模式 3.4 挤出与 BMO 3.5 修改器

目标

  • 说出 WM Operator 与 BMO 是两层表，各自管什么。
  • 亲手用 bmesh.ops.extrude_face_region 挤出——绕开 WM 层直调几何算法。
  • 阶段验收实验：脚本造棱台并挤出顶面。

概念：两层表，各管一段

按 E 挤出时（2.3 的链），WM 层负责「谁的上下文、怎么开始、撤销怎么记」；真正造几何的是 BMO 层的 extrude_face_region。分层的好处：

  • 同一个 BMO 既能被 C 操作符调，也能被 Python bmesh.ops 调——你的脚本能复刻任何编辑工具的核心算法。
  • BMO 不关心界面：输入输出都是「一槽几何元素」（geom in / geom out），可以纯数据测试。
  • WM 操作符可以组合多个 BMO（挤出 + 移动 = 两个表各出一份力）。

源码走读：一个字符串名，三个调用处

WM 侧：edbm_extrude_ex（editors/mesh/editmesh_extrude.cc:212）里 BMO_op_init(bm, &extop, BMO_FLAG_DEFAULTS, "extrude_face_region")（:231）——按字符串名点算法。

BMO 表侧：bmesh/intern/bmesh_opdefines.cc:1463 的 bmo_extrude_face_region_def：opname 正是 "extrude_face_region"（:1464），exec 是 bmo_extrude_face_region_exec（:1491），登记进总表在 :3030。

Python 侧：bmesh.ops.extrude_face_region 汇到 python/bmesh/bmesh_py_ops_call.cc:791 的同一个 BMO_op_init。三个调用处，一张表。

动手实验：脚本挤出

控制台逐段执行：

import bpy, bmesh
bm = bmesh.new()
bmesh.ops.create_cube(bm, size=2.0)
bm.faces.ensure_lookup_table()

res = bmesh.ops.extrude_face_region(bm, geom=[bm.faces[0]])
# 新几何在 res["geom"] 里；把新顶点拉高
for v in res["geom"]:
    if isinstance(v, bmesh.types.BMVert):
        v.co.z += 1.0

me = bpy.data.meshes.new("Ext")
bm.to_mesh(me); bm.free()
ob = bpy.data.objects.new("Ext", me)
bpy.context.collection.objects.link(ob)
# 预期：一个面被挤出并拉高 1 的立方体

对照 2.3 的链：你刚才手动执行了它的第 3 环（BMO），跳过了按键、poll、宏和撤销——这正是两层表的意义。

阶段 3 验收（实验）：造棱台，挤顶面

不看上面，独立写完这段（允许查 bmesh.ops 的参数名）：

import bpy, bmesh
bm = bmesh.new()
bmesh.ops.create_cone(bm, cap_ends=True, segments=4,
                      radius1=1.2, radius2=0.4, depth=1.5)
# radius2=0 就是尖顶棱锥；留个小顶面好挤

top = max(bm.faces, key=lambda f: f.calc_center_median().z)  # 找顶面
res = bmesh.ops.extrude_face_region(bm, geom=[top])
for v in res["geom"]:
    if isinstance(v, bmesh.types.BMVert):
        v.co.z += 0.6

me = bpy.data.meshes.new("Pyramid")
bm.to_mesh(me); bm.free()
ob = bpy.data.objects.new("Pyramid", me)
bpy.context.collection.objects.link(ob)
# 预期：四棱台，顶面又向上挤出一截

过关标准：能解释每一步用了哪张表、数据此刻是 BMesh 还是 DNA。
