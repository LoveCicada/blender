2.3 标脏与通知

改了一个字段，有两类听众要知道：求值器（标脏，重算依赖）和界面（通知，重画区域）。两个通道各管各——所以「改了数据 ≠ 立刻重算重画」。

路径索引 2.1 Operator 2.2 属性链 2.3 标脏与通知

目标

  • 说出 DEG_id_tag_update 与 WM_main_add_notifier 各通知谁。
  • 用实验看到：赋值那一瞬间不重算也不重画，重算发生在事件循环的空档。
  • 阶段验收：完整复述「按 E 挤出」从按键到重画的链。

概念：两类听众，两条通道

你在编辑模式挤出一个面，数据变了。谁需要知道？

  • 求值器（depsgraph）：派生数据要重算——法线、细分结果、修改器输出。给它的话叫标脏（tag）：在 ID 上打 ID_RECALC_* 标志，意思是「这份数据脏了，轮到求值时重算」。标脏本身不算任何东西。
  • 界面：3D 视图、属性面板、大纲要重画。给它们的话叫通知（notifier）：一条 NC_* | ND_* 编码的消息，订阅了这类消息的区域下次重画。

关键：两条通道都只是「捎话」。真正的重算和重画发生在事件循环的空档，不是赋值那一瞬。这就是为什么脚本里连改一百次，界面只跳到最后的结果。

源码走读：两行并排的标准动作

最干净的教学例子是编辑模式网格改完后的收尾函数 EDBM_update（editors/mesh/editmesh_utils.cc:1791），开头两行就是两条通道：

DEG_id_tag_update(&mesh->id, ID_RECALC_GEOMETRY);   /* :1795 告诉求值器：几何脏了 */
WM_main_add_notifier(NC_GEOM | ND_DATA, &mesh->id);  /* :1796 告诉界面：网格数据变了 */
  • DEG_id_tag_update：声明在 depsgraph/DEG_depsgraph.hh:123，实现在 depsgraph/intern/depsgraph_tag.cc:844。
  • WM_main_add_notifier：实现在 windowmanager/intern/wm_event_system.cc:403。
  • 消息编码：NC_GEOM = (17 << 24)（WM_types.hh:406），ND_DATA = (91 << 16)（:551）。NC 是大类，ND 是细分。

复习 2.2：rna_Object_internal_update（rna_object.cc:354）是同一模式的单人版——属性的 update 回调里只做标脏。

动手实验：重画不在赋值瞬间

控制台里逐行执行：

import bpy
ob = bpy.context.object
ob.location.x = 3.0
# 预期：立刻动了 —— 控制台每条命令之间，事件循环有空档处理通知

换成在文本编辑器里整段运行（Scripting 工作区 → 新建脚本 → Run Script）：

import bpy
ob = bpy.context.object
for i in range(50):
    ob.location.x = i * 0.2
# 预期：物体直接跳到终点，中间不画 —— 重画在事件循环，不在赋值瞬间
ob.update_tag()                  # 手动标脏（bpy 入口在 rna_ID.cc:2756）
bpy.context.view_layer.update()  # 不等事件循环，强制立刻求值一次
# 预期：无报错 —— 这就是「标脏 → 求值」两条指令的手动版

阶段 2 验收：按 E 挤出的完整链

  1. 按键：事件系统查键位映射，E → view3d.edit_mesh_extrude_move_normal（blender_default.py:5650）。分发在 wm_event_system.cc：wm_handlers_do（:3701）→ wm_handler_operator_call（:2658）→ wm_operator_invoke（:1640）。
  2. Python 操作符（view3d.py:86）：poll 检查在网格编辑模式（:94），然后调 bpy.ops.mesh.extrude_region_move（:132）。
  3. 宏（mesh_ops.cc:265）：先跑 MESH_OT_extrude_region 的 exec——edbm_extrude_region_exec（editmesh_extrude.cc:430）→ edbm_extrude_ex（:212）真正造几何；再进 TRANSFORM_OT_translate 的模态，跟着鼠标拖。
  4. 收尾：EDBM_update（editmesh_utils.cc:1791）标脏 + 通知。
  5. 空档：depsgraph 重算（阶段 4），各区域重画（阶段 5）。
