2.1 Operator 是命令

界面上的每个动作——点按钮、选菜单、按快捷键——最后都落到同一张注册表里的一个 操作符。控制台里的 bpy.ops.* 就是这张表的 Python 视图。

路径索引 1.4 Main 与 Scene 2.1 Operator 2.2 属性链 2.3 标脏与通知

目标

  • 说出操作符注册表是什么：idname 字符串 ↔ wmOperatorType 结构。
  • 说出 poll / invoke / exec 三个回调各管什么。
  • 在控制台里调用一个操作符、撤销它、亲手问一次 poll。

概念：一张表，三个回调

「添加立方体」菜单项、快捷键 Shift+A、脚本里的 bpy.ops.mesh.primitive_cube_add()——三个入口，同一个操作符。Blender 把每个用户命令登记进一张全局表：键是 idname 字符串（如 "MESH_OT_primitive_cube_add"），值是一个 wmOperatorType 结构，里面装着回调函数指针。最重要的三个：

  • poll：「现在能用吗？」返回 False 时菜单项变灰、快捷键像坏了一样。挤出操作符的 poll 要求当前在网格编辑模式。
  • invoke：「怎么开始？」弹确认框？用默认值直接跑？还是进入模态（跟着鼠标拖，直到确认）？
  • exec：「真正干活。」不许碰界面和输入设备——所以脚本能安全地直接调 exec。

两个补充：宏操作符把几个操作符串成一条（撤销时也只是一条）；操作符不只能用 C++ 写，Python 也能注册——按 E 挤出时第一个接到命令的就是个 Python 操作符。

源码走读：表和回调长什么样

回调定义在 source/blender/windowmanager/WM_types.hh:1100 的 struct wmOperatorType：

exec   /* :1124 注释明说：不能用界面代码或输入设备状态 */
invoke /* :1140 交互入口；模态操作符之后由 modal 接管 */
modal  /* :1156 持续运行的操作符（如移动、环切）逐事件处理 */
poll   /* :1164 验证当前上下文能不能执行 */

注册与查找：WM_operatortype_append（windowmanager/intern/wm_operator_type.cc:151）把操作符挂进表；WM_operatortype_find（:78）按 idname 查。网格操作符集中在 editors/mesh/mesh_ops.cc 登记，例如 MESH_OT_primitive_cube_add 在 :49（定义在 editmesh_add.cc:330）。

宏的例子：mesh_ops.cc:265 用 WM_operatortype_append_macro 登记 MESH_OT_extrude_region_move——「挤出 + 移动」一条命令、一条撤销。Python 操作符的例子：scripts/startup/bl_operators/view3d.py:86 的 VIEW3D_OT_edit_mesh_extrude_move_normal，它的 poll（:94）检查 context.mode == 'EDIT_MESH'，然后调 bpy.ops.mesh.extrude_region_move（:132）。默认键位里 E 绑的正是它（scripts/presets/keyconfig/keymap_data/blender_default.py:5650）。

动手实验：调用、撤销、问 poll

控制台（Scripting 工作区）里逐段执行：

import bpy
bpy.ops.mesh.primitive_cube_add()
len(bpy.data.objects)
# 预期：比之前多 1

bpy.ops.ed.undo()
len(bpy.data.objects)
# 预期：回到原数 —— 操作符自带撤销（ED_OT_undo 在 editors/undo/ed_undo.cc:806）
bpy.ops.mesh.extrude_region_move.poll()
# 物体模式预期：False —— poll 说「现在不行」

bpy.ops.object.mode_set(mode='EDIT')
bpy.ops.mesh.extrude_region_move.poll()
# 预期：True
bpy.ops.object.mode_set(mode='OBJECT')
bpy.ops.mesh.primitive_cube_add.get_rna_type().properties.keys()
# 预期：size / align / location / rotation / scale 等参数表
# —— 操作符的参数也是 RNA 属性（1.3 的门面再次出现）

界面印证：偏好设置 → Interface → 勾上 Python Tooltips 后，鼠标悬停任意菜单项，提示底部会写出对应的 bpy.ops.* 调用——界面自己承认背后是这张表。
