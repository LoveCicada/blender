2.2 属性链

拖 N 面板的滑条，和在控制台写 ob.location.x = 2.0，走的是同一个入口：RNA 的属性设置函数。UI、脚本、驱动、动画曲线，全从一个门进。

路径索引 2.1 Operator 2.2 属性链 2.3 标脏与通知

目标

  • 说出滑条和 bpy 赋值汇合在哪个函数。
  • 说出属性登记时挂的 update 回调在赋值后干什么。

概念：滑条不存值，它只是门把手

1.3 看了 RNA 的「读」方向（自省属性表）；这课看「写」方向。面板上的每个滑条都不是独立控件：layout.prop() 把一个按钮绑到某个 RNA 属性上。你拖动它，它调 RNA_property_float_set；你在控制台写 ob.location.x = 2.0，bpy 调的也是同一个 RNA_property_float_set。所以：

  • 值只有一份存储（DNA 字段，如 Object.loc），UI 不需要自己的副本——这就是为什么改任何一端，另一端立刻同步。
  • 滑条长什么样（单位、范围、步进）由属性的 RNA 元数据决定，面板代码只管「绑哪个属性」。
  • 设完值，RNA 会调用这个属性登记的 update 回调。它不负责画图，只负责「通知有关人员」——下一课的主角。

源码走读：从 layout.prop 到 DNA 字段

Python 面板侧：scripts/startup/bl_ui/properties_data_mesh.py:194 的 layout.prop(mesh, "texspace_location")——面板只说了「绑哪个数据块的哪个属性」。

layout.prop 的 C++ 入口：makesrna/intern/rna_ui_api.cc:1636 把 "prop" 绑到 rna_uiItemR（:164），它先用 RNA_struct_find_property（:185）按名字找到属性，再建出绑定该属性的按钮。按钮编辑最终汇入 makesrna/intern/rna_access.cc:3663 的 RNA_property_float_set（:3676 还有写值前的 set_transform 钩子）。

以 Object.location 为例，定义在 makesrna/intern/rna_object.cc:3176：

RNA_def_property(srna, "location", PROP_FLOAT, PROP_TRANSLATION);  /* :3176 */
RNA_def_property_float_sdna(prop, nullptr, "loc");                 /* :3177 存进 DNA 字段 loc */
RNA_def_property_update(prop, NC_OBJECT | ND_TRANSFORM,
                        "rna_Object_internal_update");             /* :3181 赋值后的回调 */

而 rna_Object_internal_update（:354）的函数体只有一行：DEG_id_tag_update(ptr->owner_id, ID_RECALC_TRANSFORM)（:356）——标脏，交给下一课。

动手实验：两个入口，一份存储

控制台里逐段执行：

import bpy
ob = bpy.context.object
ob.location.x = 2.0
# 预期：3D 视图里物体动了；N 面板的 Location X 同时显示 2.0
prop = ob.bl_rna.properties["location"]
prop.subtype, prop.unit
# 预期：('TRANSLATION', 'LENGTH') —— 滑条显示成「带单位的长度」就靠这份元数据

反向印证：在 N 面板把 X 拖成 5，回控制台读 ob.location.x → 5.0。拖滑条和 bpy 赋值改的是同一个 DNA 字段 loc，所以永远一致。
