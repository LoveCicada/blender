0.1 工具就位

学设计不用先编译。官方 Blender 二进制内置 bpy，是一个能摸能改的活的实例；本仓库的源码树是地图。这节课把两件工具装好、用熟。

路径索引 0.1 工具就位 1.1 一切都是数据块

目标

  • 打开官方 Blender 的 Python 控制台，执行一条 bpy 命令。
  • 会用 Ctrl+Space 补全和 dir() 列成员。
  • 给一个符号，能在源码树里搜到它的定义文件。

概念：为什么不用编译

Blender 把数据层几乎整个暴露给了内置 Python：场景里的物体、网格、材质，控制台里都能读、能改。这意味着观察设计不需要自己编译——下载官方二进制，打开控制台，就能亲手验证「数据块有用户计数」「修改器在求值时才跑」这类结论。

源码树的角色是地图：控制台里看到现象（活的），再到树里搜符号找原因（死的）。本路径每节课都是这个循环：实验先行，源码殿后。

版本对齐：本仓库源码是 Blender 5.03 alpha；官方二进制选 5.x，越接近越好。个别符号随上游漂移，以源码树为准。

源码走读：树怎么逛

三个目录够入门（完整分工见 overview.md）：

  • source/blender/ — 主体。数据布局 makesdna/、运行时 blenkernel/、编辑器 editors/、求值 depsgraph/、视口 draw/。
  • intern/ — 内部库。Cycles 在 intern/cycles/。
  • scripts/ — Python UI 与插件。面板布局在 scripts/startup/bl_ui/。

找符号用全文搜索。例子：搜 primitive_cube_add，会命中——

source/blender/editors/mesh/editmesh_add.cc:330
  void MESH_OT_primitive_cube_add(wmOperatorType *ot)   /* 定义 */
source/blender/editors/mesh/mesh_ops.cc:49
  WM_operatortype_append(MESH_OT_primitive_cube_add);   /* 注册 */

这就是「加立方体」按钮背后的命令对象。阶段 2 会回来拆它；现在只要体会：界面上每个操作，树里都有一个符号。

动手实验

打开官方 Blender，顶部切到 Scripting 工作区：左边是控制台，右边是文本编辑器。

  1. 控制台输入 bpy.context.object 回车。预期：显示当前选中物体，类似 <bpy_struct, Object("Cube") at 0x...>。
  2. 输入 dir(bpy.data)。预期：一长串成员名，找到 'meshes'、'objects'、'scenes'——下一阶段的课就围着它们转。
  3. 输入 bpy.data.meshes 后按 Ctrl+Space。预期：弹出补全列表。补全是读 bpy 最顺手的方式。
  4. 输入 bpy.ops.mesh.primitive_cube_add() 回车。预期：场景中心多一个立方体，控制台回 {'FINISHED'}。
  5. 在源码树里全文搜 primitive_cube_add，打开 editmesh_add.cc 找到 330 行附近的定义。预期：亲眼看到第 4 步那条命令的 C 定义。

第 4 步在物体模式和编辑模式都能用——同一个 Operator，行为随上下文变。先记住这个现象，阶段 2 解释。
