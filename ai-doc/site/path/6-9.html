6.9 曲线与 Curves：两代数据结构

Blender 里「曲线」有两代：老的 Curve 数据块（Bezier/NURBS，文本对象也用它），和为几何节点时代重写的 Curves（毛发的基础，属性域设计）。分清哪一代，才知道手里的 API 为什么长这样。

路径索引 6.1 几何节点 6.2 合成 6.3 雕刻 6.4 UV 6.5 权重 6.6 约束 6.7 EEVEE 探针 6.8 变换 6.9 曲线 6.10 形态键

目标

  • 说出曲线有两代数据结构，各自为什么场景设计。
  • 用 bpy 建一条 Bezier 曲线并给厚度。
  • 解释新 Curves 的「点域 / 曲线域」和 Mesh 属性体系的同构。

概念：老的多面手，新的专才

  • 老 Curve：一条曲线 = 一串 Nurb 链表；每个 Nurb 要么是 Bezier（控制点是 BezTriple：一个点 + 左右两个手柄），要么是 NURBS（控制点 + 权重）。它能挤出、倒角成管状几何，文本对象（Font）也是它——字形的轮廓就是曲线。编辑模式有自己的一套选择/手柄操作。
  • 新 Curves（3.x 起，毛发项目催生）：不要 Nurb 链表，改成和 Mesh 同思想的属性域设计——点域（每控制点位置、半径、倾斜）+ 曲线域（每根曲线的类型、循环标志）。批量处理十万根毛发时，数组化的属性远快于指针链表；几何节点读写它也零翻译成本。
  • 分工现状：建模里的放样、文字、传统曲线编辑仍走老 Curve；毛发、几何节点生成的曲线走新 Curves。两者可互转。

源码走读：两套 DNA，两个 bpy 入口

  • 老代 DNA：DNA_curve_types.h——BezTriple（:83）、Nurb（:148）、Curve（:213）。
  • 新代 DNA：DNA_curves_types.h——CurvesGeometry（:120，属性域容器）、Curves（:195，数据块本体）。
  • bpy 入口分开：老代 bpy.data.curves.new(name, type) 走 rna_main_api.cc:495；新代 bpy.data.hair_curves.new(name) 走 :831。集合名也分开：rna_main.cc:408 的 curves vs :546 的 hair_curves（:543 注释明说有意识名不同）。

动手实验：建一条有厚度的 Bezier

官方二进制控制台逐段执行：

import bpy
cu = bpy.data.curves.new("MyBez", 'CURVE')
cu.dimensions = '3D'
spl = cu.splines.new('BEZIER')
spl.bezier_points.add(1)
# 预期：两个贝塞尔控制点（new 自带一个，add(1) 再添一个）
bp0, bp1 = spl.bezier_points
bp0.co = (0, 0, 0)
bp1.co = (2, 2, 0)
bp0.handle_left_type = bp0.handle_right_type = 'AUTO'
bp1.handle_left_type = bp1.handle_right_type = 'AUTO'
# 预期：手柄设自动 —— BezTriple 的点+双手柄结构在 bpy 里原样可见
cu.bevel_depth = 0.1
ob = bpy.data.objects.new("MyCurve", cu)
bpy.context.scene.collection.objects.link(ob)
# 预期：场景里出现一条有厚度的曲线管 —— bevel 是 Curve DNA 上的参数
fur = bpy.data.hair_curves.new("Fur")
type(fur).__name__, fur.bl_rna.identifier
# 预期：('Curves', 'Curves') —— 新代是另一个数据块类型，不是老 Curve
