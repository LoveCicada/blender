3.2 亲手玩 BMesh

Python 的 bmesh 模块就是 C 层 BMesh 的封装。三板斧：bmesh.new() 造空网、bmesh.ops.* 调几何算法、bm.to_mesh(me) 写回 DNA。这节课从空造出一个物体。

路径索引 3.1 两种表示 3.2 玩 BMesh 3.3 编辑模式

目标

  • 会用 bmesh 模块从空 Mesh 造几何并链进场景。
  • 记住生命周期：new → 操作 → to_mesh/from_mesh → free。

概念：脚本里的指针网

bmesh 模块（C 实现在 source/blender/python/bmesh/）把上一课的指针网完整暴露给 Python：顶点、边、loop、面都能拿到、能改、能问邻接。典型用法是「离线造几何」：

  1. bmesh.new()：造一张空 BMesh（此刻和场景毫无关系）。
  2. bmesh.ops.*：调 BMO 算法造形——create_cube、create_cone、extrude_face_region……和编辑模式工具用的是同一张算法表（3.4 细讲）。
  3. bm.to_mesh(me)：把指针网转回数组 Mesh（DNA），这才能进场景。
  4. bm.free()：释放。BMesh 是 Blender 管理的原生内存，不 free 会泄漏——它不等你存盘，也不进 .blend。

反过来 bm.from_mesh(me) 把现有网格读成 BMesh，改完再 to_mesh 写回——「读改回」三步是脚本改网格的标准姿势。

源码走读：Python 调用落到哪

bmesh.ops.create_cube(...) 这样的调用，最终在 python/bmesh/bmesh_py_ops_call.cc:791 汇到 BMO_op_init(bm, &bmop, BMO_FLAG_DEFAULTS, self->opname)——和 C 操作符调的是同一张 BMO 表。写回 DNA 的转换核心是 BM_mesh_bm_to_me（bmesh/intern/bmesh_mesh_convert.cc:1668）；反向是 BM_mesh_bm_from_me（:318）。

动手实验（王牌）：从空造一个立方体

控制台逐段执行：

import bpy, bmesh
bm = bmesh.new()
bmesh.ops.create_cube(bm, size=2.0)   # BMO 造几何

me = bpy.data.meshes.new("FromBM")
bm.to_mesh(me)                        # BMesh → DNA 网格
bm.free()                             # 释放，别忘

ob = bpy.data.objects.new("FromBM", me)
bpy.context.collection.objects.link(ob)
# 预期：场景里出现一个立方体，名叫 FromBM

「读改回」：把它的 0 号顶点拉高——

bm = bmesh.new()
bm.from_mesh(me)                      # DNA → BMesh
bm.verts.ensure_lookup_table()
bm.verts[0].co.z = 2.0
bm.to_mesh(me)                        # 写回
bm.free()
# 预期：立方体一个角被拉高

注意 ensure_lookup_table()：BMesh 本质是指针网，按下标取值前要先建一次索引表——这行代码本身就是 3.1 两种表示差异的活证据。
