按顺序学，按课动手

六阶段二十七课。每课六段：目标 → 概念 → 源码走读 → 动手实验 → 自检 → 拓展。实验在官方 Blender 的 Python 控制台里做，不用编译。术语卡住就查词汇表。

阶段 0 · 环境与读码

  1. 0.1 工具就位：控制台、补全、在源码树里搜符号。

阶段 1 · 数据地基：ID / DNA / RNA / Main

  1. 1.1 一切都是数据块：ID 头、用户计数、伪用户。
  2. 1.2 DNA 是磁盘布局：哪些字段进 .blend，哪些不进。
  3. 1.3 RNA 是对外门面：面板与 bpy 为什么都经过 RNA。
  4. 1.4 Main 与 Scene：进程里的 ID 数据库 vs 一幕场景。

阶段 2 · 一次点击的完整旅程

  1. 2.1 Operator 是命令：注册表；poll / invoke / exec；调用、撤销、问 poll。
  2. 2.2 属性链：拖滑条和 bpy 赋值是同一入口。
  3. 2.3 标脏与通知：两类听众；「按 E 挤出」完整链验收。

阶段 3 · 建模核心

  1. 3.1 两种网格表示：数组 Mesh vs 指针网 BMesh，各适合什么。
  2. 3.2 亲手玩 BMesh：王牌实验——从空造一个立方体。
  3. 3.3 编辑模式的进出：Tab 是一次格式转换；编辑态里 DNA 不变。
  4. 3.4 挤出与 BMO：两张操作符表；脚本造棱台挤顶面（验收）。
  5. 3.5 修改器：参数进 DNA，变形在求值。

阶段 4 · 求值与分身

  1. 4.1 depsgraph 与求值副本：原始 ID 不动，求值写副本。
  2. 4.2 两张图：视口图 vs 渲染图，建图时定模式。

阶段 5 · 渲染分道

  1. 5.1 视口一帧：Draw Manager 假定图已求过；overlay 不是引擎。
  2. 5.2 EEVEE 与 GPU 材质：材质预览常走 EEVEE；节点编译成 GPU 材质。
  3. 5.3 F12 链：RENDER_OT_render → RE_RenderFrame → RE_engine_render。
  4. 5.4 Cycles 接入：从 depsgraph 同步，不读编辑态 BMesh。
  5. 5.5 颜色管理入门：线性到显示器之间的视图变换。

阶段 6 · 自选专题

  1. 6.1 几何节点：修改器里的程序；字段按上下文求值。
  2. 6.2 合成：F12 链末尾的节点树；引擎管算，合成管修。
  3. 6.3 雕刻：PBVH 与笔画管线；为什么不用 BMesh。
  4. 6.4 UV 展开：面角上的数据；8 顶点为什么有 24 份 UV。
  5. 6.5 权重与顶点组：顶点域的数据；数值在网格，名单在物体。
  6. 6.6 约束：求值时算变换；location 不变，matrix_world 变。
  7. 6.7 EEVEE 探针：光栅引擎的间接光；预计算缓存 vs 路径追踪。

怎么用这条路径

  • 按顺序读。后面的课假定前面的实验做过。
  • 实验必做：在控制台里亲手看到现象，再去源码找原因。
  • 每课末尾的自检链到二百问答，合上笔记能答才算过。
