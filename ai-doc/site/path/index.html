按顺序学，按课动手

六阶段二十课。每课六段：目标 → 概念 → 源码走读 → 动手实验 → 自检 → 拓展。实验在官方 Blender 的 Python 控制台里做，不用编译。术语卡住就查词汇表。

阶段 0 · 环境与读码

  1. 0.1 工具就位：控制台、补全、在源码树里搜符号。

阶段 1 · 数据地基：ID / DNA / RNA / Main

  1. 1.1 一切都是数据块：ID 头、用户计数、伪用户。
  2. 1.2 DNA 是磁盘布局：哪些字段进 .blend，哪些不进。
  3. 1.3 RNA 是对外门面：面板与 bpy 为什么都经过 RNA。
  4. 1.4 Main 与 Scene：进程里的 ID 数据库 vs 一幕场景。

后续阶段（未开）

  • 阶段 2 · 一次点击的旅程：Operator；属性链；标脏与通知。
  • 阶段 3 · 建模核心：Mesh vs BMesh；bmesh 模块实验；编辑模式；挤出与 BMO；修改器。
  • 阶段 4 · 求值与分身：depsgraph 与 COW；视口图 vs 渲染图。
  • 阶段 5 · 渲染分道：视口一帧；EEVEE；F12 链；Cycles；颜色管理。
  • 阶段 6 · 自选专题：几何节点 / 合成 / 雕刻 / UV，按兴趣开。

怎么用这条路径

  • 按顺序读。后面的课假定前面的实验做过。
  • 实验必做：在控制台里亲手看到现象，再去源码找原因。
  • 每课末尾的自检链到二百问答，合上笔记能答才算过。
