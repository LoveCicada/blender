阶段 1 · 数据地基 · 第 1 课

1.1 一切都是数据块

Blender 里的「东西」——物体、网格、材质、场景——都是数据块。每个数据块开头是同一个 ID 头，所以它们共享一套名字、计数和存盘规则。

路径索引 0.1 工具就位 1.1 数据块 1.2 DNA

目标

  • 说出 ID 头管什么：名字（带类型码）、用户计数、脏标记、自定义属性。
  • 在控制台里演示用户计数的增、减和伪用户。

概念：一个头，管所有「东西」

新建一个立方体，你其实造了两个数据块：一个 Object（物体，管位置旋转缩放），一个 Mesh（网格，管顶点面）。材质、相机、灯光、场景，全都是数据块。它们类型不同，但开头都是同一个 ID 结构，所以——

  • 都有唯一名字，名字前两个字符是类型码：网格是 ME，物体是 OB，场景是 SCE。界面上显示的 "Cube" 是名字去掉类型码的部分。
  • 都有用户计数 us：这份数据被几个地方引用。两个物体共用一份网格，网格的计数就是 2。
  • 都有脏标记 recalc：改过了、需要重算。阶段 2、4 会反复遇到它。
  • 都能挂自定义属性（面板里的「自定义属性」、脚本里的 ob["my_key"]）。

源码走读：ID 头长什么样

source/blender/makesdna/DNA_ID.h:415 的 struct ID：

char name[258];        /* :433  前两字节是 ID_Type 类型码 */
int us;                /* :444  用户计数 */
unsigned int recalc;   /* :446  脏标记，给 depsgraph / undo 用 */
IDProperty *properties;/* :481  自定义属性 */

再打开 DNA_mesh_types.h:147 的 struct Mesh，第一个成员就是 ID id;（:154）。Object、Scene 同理。这就是「开头相同」的落点。

动手实验：用户计数与伪用户

控制台（Scripting 工作区）里逐段执行：

import bpy
me = bpy.data.meshes.new("Shared")   # 一份空网格
a = bpy.data.objects.new("A", me)    # 两个物体共用
b = bpy.data.objects.new("B", me)
bpy.context.collection.objects.link(a)
bpy.context.collection.objects.link(b)
me.users
# 预期：2
me.use_fake_user = True              # 开伪用户
bpy.data.objects.remove(a, do_unlink=True)
bpy.data.objects.remove(b, do_unlink=True)
me.users
# 预期：1（伪用户占一个计数）
"Shared" in bpy.data.meshes
# 预期：True —— 没人引用也没消失
me.use_fake_user = False
bpy.data.orphans_purge(do_recursive=True)
"Shared" in bpy.data.meshes
# 预期：False —— 孤儿被清掉

界面印证：大纲视图（Outliner）切到 Orphan Data 显示模式，能看到没被引用的数据块；伪用户就是那个盾牌图标的含义。
