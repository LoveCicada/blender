5.5 颜色管理入门

渲染引擎算出的线性数值，到显示器之间还要过一道视图变换（默认 AgX）。它只改「怎么显示」，不改场景数据——所以同一张渲染图，换个变换就换副面孔。

路径索引 5.4 Cycles 5.5 颜色管理

目标

  • 说出渲染结果到显示器经过什么：线性 → 视图变换 → 显示设备。
  • 用 view_settings 改变换，看同一张图的变化。

概念：最后一公里的变换

引擎算出的是线性光数值（可以远大于 1）。显示器只有 0–1，还有人眼的非线性偏好。中间这道换算就是颜色管理，Blender 用 OpenColorIO（OCIO）实现：

  • 视图变换（view transform）：默认 AgX——把高动态范围压进显示范围，高光不过曝、肤色自然。老选项 Standard 基本不做压缩，高光容易死白。
  • 显示设备（display device）：通常是 sRGB。
  • 两者都是 Scene 上的设置（view_settings / display_settings），是 DNA——存盘跟着文件走。

关键：变换发生在「算完之后、显示之前」。改它不重渲染、不动几何材质，只换显示效果。本课点到为止——深入 OCIO 配置属于阶段 6 自选专题。

源码走读：设置与实现

  • Scene 上的两个设置块：rna_scene.cc:6839 的 view_settings、:6844 的 display_settings（都是指针属性，指向 DNA 字段）。
  • 实现层：source/blender/imbuf/intern/colormanagement.cc——图像缓冲的显示变换在这里套。
  • 变换定义来自 OCIO 配置：release/datafiles/colormanagement/config.ocio（AgX、Standard 等都在里面登记）。

动手实验：同一张图，两副面孔

先渲一张（5.3 的链），然后控制台逐段执行：

import bpy
scene = bpy.context.scene
scene.view_settings.view_transform
# 预期：'AgX'（5.x 默认）
scene.view_settings.bl_rna.properties["view_transform"].enum_items.keys()
# 预期：['AgX', 'Standard', ...] 一类 —— 可用变换表（来自 OCIO 配置）
scene.view_settings.view_transform = 'Standard'
# 预期：Render Result / 视口渲染图立刻变样（高光更硬、可能过曝）
# —— 没有重新渲染：只换了显示变换

scene.view_settings.view_transform = 'AgX'
# 换回来

注意实验里没有 bpy.ops.render.render()：变换是显示层的事，改设置触发标脏（2.3），图像缓冲重过一遍变换就完了。
