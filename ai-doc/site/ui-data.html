UI 怎样碰到数据

先记这条链。函数级走读：数据（DNA、RNA、Python UI、Operator、更新与撤销）。

目录 模块 职责 功能 UI–数据 渲染地图

Python / C UI → RNA → Operator → BKE / DNA → notifier → depsgraph

记三件事就够

  1. 面板上的数字几乎都是 RNA 属性，绑定 DNA 字段或 getter/setter，不是另一份平行数据。
  2. 菜单和快捷键指向 wmOperatorType（WM_operatortype_append）。真正改网格的是 editors 里的 exec，不是 bl_ui。
  3. 改完要让别人知道：notifier / depsgraph 标脏。视口不会去轮询每个顶点。
