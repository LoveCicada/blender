投影 1

按源码模块

分组对齐 source/blender/CMakeLists.txt 与 intern/cycles。点名称进目录看职责和邻居。

数据与文件

  • makesdna — 结构布局
  • makesrna — 属性反射
  • blenkernel — 运行时 ID / Mesh
  • blenloader — .blend 读写

网格与几何

  • bmesh — 编辑态拓扑
  • geometry — 属性与几何求值
  • modifiers — 修改器实现

命令与界面

  • windowmanager
  • editors/mesh、object、transform
  • editors/space_view3d、editors/render
  • scripts/startup/bl_ui

求值、绘制、渲染

  • depsgraph
  • draw → eevee / workbench / gpu
  • render → intern/cycles
  • nodes/shader

弱写：compositor、sequencer、io、GHOST、雕刻细目录。它们在 CMake 里存在，本轮地图不建条目。

模块树会随官方 CMake 变；条目语义以目录页为准。
