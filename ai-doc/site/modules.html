按源码模块

分组对齐 source/blender/CMakeLists.txt 与 intern/cycles。CMake 切的是编译单元，不是用户菜单。点名称进目录看职责和邻居。

它解决什么

读源码时第一个问题是「这个目录编译成什么」。CMake 把 DNA、BKE、editors、draw、Cycles 拆开，是因为它们的生命周期不同：有的生成表，有的改拓扑，有的出像素。投影只解释这种切法，不另起子系统名单。

一条邻居链（挤出之后谁接手）

用户在编辑模式按 E。跨模块的顺序是固定的，不要从 draw/ 或 intern/cycles 里找挤出：

editors/mesh/editmesh_extrude.cc
  MESH_OT_extrude_region → edbm_extrude_ex
    BMO_op_init(..., "extrude_face_region")   /* bmesh */
    BMO_op_exec
  EDBM_update                                  /* editors + BKE tag */
    DEG_id_tag_update(&mesh->id, ID_RECALC_GEOMETRY)
blenkernel/intern/object_update.cc
  BKE_object_eval_uber_data → mesh_calc_modifiers / editbmesh_calc_modifiers
draw/intern/draw_context.cc
  DRW_draw_view                                /* 视口 */
/* 或 editors/render/render_internal.cc
  RENDER_OT_render → RE_engine_render          /* F12 / Cycles */

editors/mesh 听快捷键；bmesh 改半边；blenkernel 在求值时叠修改器；最后才分给 draw 或 Cycles。

数据与文件

source/blender/CMakeLists.txt 先列一整份 SRC_DNA_INC（DNA_mesh_types.h、DNA_object_types.h…）。makesdna 在构建期扫这些头，编成当前进程的 SDNA。makesrna 另跑一遍定义表，给同一字段起对外名字。blenkernel 是运行时对象（Main 里的 ID、合法 Mesh）。blenloader 读写 .blend，打开文件时用文件里的 DNA1 对齐旧布局。

  • makesdna — 结构布局
  • makesrna — 属性反射
  • blenkernel — 运行时 ID / Mesh
  • blenloader — .blend 读写

网格与几何

磁盘上的网格是数组 Mesh。编辑需要半边，所以 bmesh 单独成库，不写进 DNA。geometry 是无状态算法（属性域、Geometry Set），给几何节点用，不提供挤出。modifiers 的 modify_mesh 只在 depsgraph 求值时跑，改的是副本。

  • bmesh — 编辑态拓扑
  • geometry — 属性与几何求值
  • modifiers — 修改器实现

命令与界面

windowmanager 的 WM_main（wm.cc）先 wm_event_do_refresh_wm_and_depsgraph，再收事件、跑 handler、notifier、绘制。editors 按空间拆：mesh 改拓扑，object 管模式，transform 管 G/R/S，View3D 画视口，render 触发 F12。bl_ui 只 layout.prop / layout.operator，不改顶点。

  • windowmanager — WM_main 循环
  • editors/mesh、object、transform
  • editors/space_view3d、editors/render
  • scripts/startup/bl_ui

求值、绘制、渲染

depsgraph 编「谁依赖谁」，对外入口是 DEG_evaluate_on_refresh / on_framechange。draw 假定图已经求过：view3d_main_region_draw → view3d_draw_view → DRW_draw_view。EEVEE / Workbench 住在 draw/engines/，因为它们吃同一套 Draw Manager。Cycles 在 intern/：经 RE_engine_render 接到 render。同一份 shader nodes 编两次。

  • depsgraph
  • draw → eevee / workbench / gpu
  • render → intern/cycles
  • nodes/shader

和邻居的边界

模块它写它不写
editors/mesh用户命令、poll、EDBM_update半边重连算法（在 bmesh）

modifiers求值时变形副本编辑模式的挤出
draw / Cycles像素拓扑

设计选择

CMake 目录按生命周期切，不按用户菜单切。菜单在 bl_ui，算法在 C 模块。

常见误解

CMake 里有 compositor / io / sculpt，不等于本站目录条目。弱写的不建权威名字。
